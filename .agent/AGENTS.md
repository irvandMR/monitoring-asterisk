## Core Rules

- Use Next.js.
- Use TypeScript.
- Follow the architecture defined in `.agent/03-architecture.md`.
- Follow UI rules defined in `.agent/02-ui-design.md`.
- Follow implementation order defined in `.agent/04-implementation-plan.md`.
- Do not invent APIs or backend behavior.
- Reuse existing components before creating new ones.
- Keep the implementation simple and maintainable.
